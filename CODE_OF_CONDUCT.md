# Code of Conduct

## Our Pledge

We want `replicate-openai` to be a welcoming, useful project for people building OpenAI-compatible tooling on top of Replicate. We pledge to make participation in this project respectful and harassment-free for everyone, regardless of background, experience level, or identity.

## Expected Behavior

- Be kind, patient, and constructive.
- Assume good intent, especially when discussing bugs or design tradeoffs.
- Keep feedback focused on the code, docs, behavior, and user impact.
- Respect maintainers' time by keeping issues and pull requests clear and scoped.
- Help make the project safer by avoiding the disclosure of secrets, API tokens, or private user data.

## Unacceptable Behavior

- Harassment, intimidation, threats, or personal attacks.
- Discriminatory language or conduct.
- Trolling, sustained disruption, or bad-faith arguments.
- Publishing private information, credentials, logs, or tokens without explicit permission.
- Any behavior that makes the project unsafe or unwelcoming for contributors or users.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this Code of Conduct. Maintainers may also temporarily or permanently ban participants for behavior that they determine is harmful to the project or community.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainers privately through the repository owner's GitHub profile or by opening a minimal issue that asks for a private contact path. Do not include sensitive details, private logs, or personal information in a public issue.

Reports will be reviewed as promptly and fairly as possible. Maintainers will respect the privacy and safety of reporters when handling incidents.
